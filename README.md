## 📌 Tutorial Objective

This tutorial presents the steps required to **create and deploy a Java EE (J2EE) web service** using:

* the **NetBeans 6.5** IDE
* the integrated **GlassFish** application server

It also demonstrates how to develop and test **several types of clients** that consume this web service:
* Java client
* C# client
* ASP.NET client
* Flex client

The code is not explained line by line. This document is therefore intended for developers who already have some experience with:
* Java EE
* EJB 3
* JPA
* NetBeans

## 🏗️ Course Content

The tutorial covers, in particular:

* Designing a Java EE web service
* Deployment on the GlassFish server
* Accessing data via JPA
* Consuming the web service across different technology environments:

  * Java SE
  * .NET (C#, ASP.NET)
  * Flex

The fundamental concepts used (EJB3, JPA, Java EE architecture) are assumed to be known or covered in supplementary resources referenced in the tutorial.

## 🎯 Target Audience

This document is primarily intended for:

* Students studying Java EE development
